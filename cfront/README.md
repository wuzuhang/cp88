# 球序 H5

Vue 3 + Vite 的双色球分析前端，参考 `cp88/src/views/other.vue` 的出球位置统计方式，使用 Go 后端中的真实开奖记录。

## 启动

先从项目根目录启动后端 `go run .`，再在 `cfront` 中执行：

```sh
npm install
npm run dev
```

访问 `http://127.0.0.1:5173`。开发服务器将 `/api` 代理到 `http://127.0.0.1:8080`，无需另行设置 CORS。代理地址可在 `.env.local` 中设置 `API_PROXY_TARGET`。

## 页面与统计口径

- 频次矩阵：六列使用实际出球顺序 `seq_red_1`–`seq_red_6`，红球默认统计近 100 期，可选 100、200、300、400、500、600、700、800、900、1000 期共十档；蓝球同样默认统计近 100 期，可选 100–1000 期共十档。左列统计全部红球次数，各位置列分别按频次排序，相同行不是一组号码。
- 历史对照：向前一期时，载入该期的实际出球顺序，统计窗口只使用更早的期数，排除对照期及后续开奖。
- 号码选择：最多六个不同红球和一个蓝球，支持按位置选择、直接选号、随机生成与清空。
- 组合分析：调用后端，显示红球和值、跨度、奇偶及三区比例。修改号码后清除旧结果。
- 开奖历史：初次分页加载最新 1500 期，覆盖最高 1000 期样本并预留历史对照范围；支持筛选已加载的期号/日期，加载更多可继续读取数据库中的早期记录。
- 手机底部保留选号进度、随机选号及分析按钮，支持安全区域；页面也适配平板与桌面。

统计描述历史分布，不推断中奖概率。

矩阵颜色按实际样本期数动态归一化。每列平均频次为实际期数除以号码数量（红球 33、蓝球 16）；浅至深五档分别表示不超过均值的 50%、85%、115%、150% 及高于 150%。同一出现比例在 100 期与 1000 期中使用相同颜色，切换历史窗口后也会重新计算。

## 接口

- `GET /api/v1/records?limit=500&offset=0`：返回 `items`、`total`、`limit`、`offset`，按日期和期号降序。
- `POST /api/v1/analysis`：传入 `red_balls` 和 `blue_ball`，返回组合特征。

## 检查与构建

```sh
npm test
npm run build
npm run preview
```

构建输出为 `cfront/dist`。根目录 Dockerfile 包含前后端构建阶段，执行 `docker compose up --build -d` 部署 Go 后端与 Nginx H5 前端。默认访问 `http://localhost`，Nginx 将 `/api` 转发到后端。数据库及端口配置见根目录 README。
